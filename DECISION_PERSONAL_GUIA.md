# 💔 GUÍA: LA DECISIÓN MÁS DIFÍCIL (Reducción de Personal)

**Esta es probablemente la conversación más dura que tendrás.**  
**Aquí te doy un marco para hacerlo bien.**

---

## 🧠 PRIMERO: MENTALIDAD

### La Realidad Brutal

```
¿Quieres mantener 5 personas?
✓ Buena voluntad ✓ Lealtad ✓ Humanidad

¿Cuál es el costo?
❌ El negocio quiebra en 3 meses
❌ Pierdes TODO (dinero, negocio, casa)
❌ Nadie cobra nada (ni siquiera los que mantienes)
```

### La Verdad Incómoda

```
Reducir 1 persona AHORA = Salvar negocio
Mantener 5 personas AHORA = Perder dinero + despedir 5 en 3 meses
```

**Elección:** Difícil ahora o catastrófica después.

### Mentalidad Correcta

```
NO eres un malo por reducir personal.
ERES UN RESPONSABLE por salvar el negocio.

Mantener gente que no puedes pagar = cruelty también
```

## 📋 PASO 1: ANÁLISIS FRÍO (Sin emociones aún)

Haz esto SOLO, en tu casa, sin presión.

### Matriz de Decisión

Para CADA persona, completa esto:

```
NOMBRE: ________________
ROL: [Supervisora / Operaria / Apoyo]
SUELDO: $ ________________
ANTIGÜEDAD: _______ meses/años

CRÍTICA para operaciones:
  □ SÍ - Sin esta persona, no puedo producir
  □ PARCIAL - Puedo producir menos pero funcionamos
  □ NO - Tengo cobertura

PRODUCTIVIDAD:
  □ Alta (Top performer)
  □ Media (Sólida)
  □ Baja (Problemas?)

FLEXIBILIDAD:
  □ Podría hacer tiempo parcial (15-20 horas)?
  □ Podría hacer pausa (2-3 meses)?
  □ Necesita full-time o nada

REACCIÓN AL CAMBIO:
  □ Flexible, entiende negocio
  □ Puede entender con explicación
  □ Difícil, posible conflicto

ALTERNATIVAS:
  □ Tiempo parcial por X meses
  □ Pausa temporal (vuelve cuando mejore)
  □ Reducción hora-trabajo
  □ Solo despido

IMPACTO PRODUCCIÓN si se va:
  □ Producción se reduce 10% (mínimo)
  □ Producción se reduce 20%
  □ Producción se reduce 30%+
  □ Producción colapsa

COSTO EMOCIONAL para TI:
  □ Bajo (la debo despedir)
  □ Medio (persona buena, necesario)
  □ Alto (persona querida, duro)
  □ Muy alto (no puedo)
```

### Después de analizar a TODAS:

```
Matriz de Reducción (mejor a peor opción):

Persona Z: Despido temporal (DIFÍCIL - probablemente no vuelva)
```

## 🎯 PASO 2: DECISIÓN FINAL

### Opción A: Mantener 5 (No recomendado)

**Pros:**
- No tienes conversación difícil ahorita
- Equipo feliz este mes
- Paz mental corto plazo

**Contras:**
- Pierdes $14,274/mes
- En 3 meses: Dinero se acaba
- Luego despides TODOS en pánico
- Peor desenlace posible

**Cuándo elegir esto:**
- Solo si tienes dinero para aguantar 3 meses más
- Y confías 100% en llegar a 43 muñecas consistentes
- Y puedes aumentar precio otro 15% (difícil)

---

### Opción B: Reducir a 4 (RECOMENDADO)

**Pros:**
- Llegas a break-even (-$1,774/mes)
- Mostrar responsabilidad (no alarma)
- Probablemente reversible en 2-3 meses
- Persona reducida puede ayudar puntuales

**Contras:**
- Conversación difícil
- Posible molestia temporal
- Baja pequeña en producción (20%)

**Quién reducir:**
- Candidato 1: Persona de apoyo (no directa en operarias)
- Candidato 2: Operaria menos productiva
- **Evitar:** Supervisora (es tu brazo derecho)

**Cómo hacerlo:**
- Pausa temporal (2-3 meses)
- Ofrece ayuda puntuales (paga como freelance)
- Promete reintegración con números

---

### Opción C: Reducir a 3 (Agresivo)

**Pros:**
- Ganancias reales (+$8,226/mes)
- En 3 meses: +$25,000 en caja
- Negocio viable y crecible

**Contras:**
- Conversación MUY difícil (2 personas)
- Probable conflicto/resentimiento
- Producción baja inicialmente (30%)
- Riesgo: Personas se van y se llevan otros clientes

**Quién reducir:**
- Si es necesario: Operaria 1 + Operaria 2 (no supervisoras)
- Mantienes: Supervisora + 1-2 operarias top

**Cuándo elegir:**
- Solo si realmente no hay opción
- Y tienes presupuesto para aguantar 1-2 meses difíciles
- Y puedes recuperarlas en 60-90 días

## 💬 PASO 3: LA CONVERSACIÓN DIFÍCIL

### ANTES de hablar

**Prepárate emocionalmente:**
- [ ] Respira 5 min antes
- [ ] Recuerda: Es lo mejor para TODOS (equipo incluido)
- [ ] Sé empático pero firme

**Elige lugar y tiempo:**
- [ ] Privado (no frente a otros)
- [ ] Mañana (tienen todo día para procesar)
- [ ] 15 min máximo (no alargar agonía)

**Prepara documentos:**
- [ ] Fecha de cambio (ejemplo: Sept 1)
- [ ] Duración (ejemplo: 2-3 meses)
- [ ] Cómo se reintegra (si es pausa)
- [ ] Pago durante pausa (si aplica)

---

### LA CONVERSACIÓN (Estructura)

#### APERTURA (1 min) - Honesto y directo

```
"[Nombre], necesito hablar contigo de algo importante.
Siéntate, esto puede ser difícil de escuchar.
Te lo digo directamente porque mereces honestidad."
```

#### CONTEXTO (2 min) - Explica sin suavizar

```
"El negocio está en crisis. Hemos tenido menos ventas, 
y con 5 personas + gastos, pierdo $38,000 cada mes.

Esto NO es por ti o tu trabajo.
Esto es por la realidad del negocio.

Si no cambio algo, en 3 meses no tengo dinero 
para pagar a NADIE, incluyéndome a mí."
```

#### LA DECISIÓN (1 min) - Claro y final

**Si es PAUSA:**
```
"Lo que necesito es que hagas una pausa de [2-3] meses.
Puedes ayudar en proyectos puntuales y te pago por horas.
Después de [fecha], vuelves full-time si números mejoran."
```

**Si es TIEMPO PARCIAL:**
```
"Necesito reducirte a [X] horas/semana en lugar de full-time.
Mismo sueldo prorrateado, claro.
Es temporal, máximo 3 meses mientras reorganizo."
```

**Si es DESPIDO TEMPORAL:**
```
"Necesito que dejes el puesto el [fecha].
Es temporal, por 2-3 meses.
Cuando números mejoren, vuelves."
```

#### JUSTIFICACIÓN (1-2 min) - Si preguntan "¿por qué yo?"

```
"Elegí esto porque:
- Tu rol permite hacerlo (comparado con otros)
- Confío que entiendes el negocio
- Espero que puedas volver pronto

No es porque seas mala persona o mala trabajadora.
Es una decisión de números."
```

#### OFRECIMIENTOS (1 min) - Muestra consideración

```
"Durante estos [2-3] meses:
- Puedes hacer trabajos puntuales (te pago por horas)
- Puedo ayudarte a encontrar empleo temporal si lo necesitas
- Vuelves SÍ o SÍ cuando mejore

¿Preguntas?"
```

#### CIERRE (30 seg) - Firme pero empático

```
"Sé que es difícil. Yo estoy así también.
Pero esto salva el negocio para todos.
Conozco la fecha: [X].

¿De acuerdo?"
```

## 🚨 ESCENARIOS POSIBLES

### ESCENARIO 1: Acepta bien
```
"Ok, entiendo. ¿Qué puedo hacer?"

Respuesta:
"Gracias por entenderlo. Aquí está la propuesta por escrito.
Vamos a mantener esto privado, ¿ok?
Contigo si tienes dudas."

STATUS: ✓ Excelente, fácil transición
```

### ESCENARIO 2: Se enoja
```
"¡Qué! ¿Así me tratas después de X años?"

Respuesta (calmado):
"Entiendo tu enojo. Yo también estoy enojado.
Pero el negocio está en crisis.
Esta decisión es para salvar el negocio.

Si hay alternativa, la escucho. 
Pero algo tiene que cambiar."

STATUS: ⚠️ Difícil pero manejable. Déjalo procesar.
```

### ESCENARIO 3: Llora
```
[Persona llora]

Respuesta (empático):
"Sé que duele. Yo también lo siento.
Pero vamos a salir de esto juntos.

Esta es temporal. Cuando mejore, vuelves.
Confío en ti."

STATUS: 😔 Emocional pero manejable. Dale tiempo.
```

### ESCENARIO 4: Amenaza irse / problemas
```
"Me voy ahora mismo" 
o 
"Voy a decirle a otros clientes que..."

Respuesta (firme):
"Entiendo tu molestia. 
Pero la decisión está tomada.

Si decides irte, respeto.
Si quieres hablar con abogado, está bien.
Pero esto se mantiene."

STATUS: 🔴 Conflict. Documenta TODO. Considera apoyarte legalmente.
```

## 📝 DESPUÉS de la conversación

### INMEDIATO (mismo día)

- [ ] Documenta por escrito qué acordaste
- [ ] Envía correo confirmando fechas y términos
- [ ] Guarda copia (por ley)
- [ ] Informa a Supervisora (aliada)

### COMUNICACIÓN CON EQUIPO

**NO les digas a todos.**  
**Hasta que sea necesario.**

Solo cuando:
- Persona lo hizo público
- Cambio afecta directamente producción
- Es mejor controlar el mensaje

**Mensaje simple:**
```
"Estamos haciendo cambios temporales 
para estabilizar el negocio.
[Persona] está en pausa, pero vuelve cuando mejore.
Esto nos ayuda a todos a sobrevivir."
```

## 📈 REINTEGRACIÓN (Cuando mejora)

### Si fue PAUSA (mejor escenario)

```
Mes 2-3: "Números están mejorando. 
Vuelves el [fecha]?"

Generalmente: Persona dice SÍ
Beneficio: Se sintió temporal, no traición
```

### Si fue TIEMPO PARCIAL

```
Mes 2: "¿Podemos subirte a [X] horas?"
Mes 3: "Full-time de vuelta?"

Escalada gradual = Menos conflicto
```

### Si fue DESPIDO TEMPORAL

```
Mes 2: "Nos va mejor. ¿Quieres volver?"

⚠️ Posible: Persona dice NO
Realidad: Buscó otro empleo en pausa
Aceptación: Está bien, merece estabilidad
```
